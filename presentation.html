7. Percentage & Grade Calculation

Formulas, Step-by-Step Example, and Grading Scale

08
PERCENTAGE CALCULATION & EXAMPLE
CALCULATION FORMULA:

Percentage = (Total Marks Obtained / Maximum Total Marks) × 100

WORKED EXAMPLE (3 SUBJECTS):
• Java Programming = 85 / 100 • Mathematics III = 90 / 100 • Data Structures = 75 / 100 -------------------------------------------- Total Marks Obtained = 85 + 90 + 75 = 250 Maximum Total Marks = 3 × 100 = 300 Percentage = (250 / 300) × 100 = 83.33% Resulting Grade = A (Excellent)

HOW JAVA STREAM API IS USED
  • Class Average:
    students.stream().mapToDouble(Student::getPercentage).average()
  • Class Topper:
    students.stream().max(Comparator.comparingDouble(...))
  • Pass / Fail Counts:
    students.stream().filter(s -> !s.getGrade().equals("F")).count()
  • Grade Distribution:
    Collectors.groupingBy(Student::getGrade, TreeMap::new, ...)

11. File Handling & Backup System

Persistent Storage Architecture and Automated Disaster Recovery

12
PRIMARY STORAGE (students.txt)
  • Storage Target: Permanent disk file named students.txt.
  • Saving Engine: FileWriter & PrintWriter write formatted lines.
  • Loading Engine: FileReader & BufferedReader restore records on launch.
  • Pipe Format: SUBJECTS|... & STUDENT|101|...
  • Persistence: Data remains available across application restarts.
BACKUP ENGINE (students_backup.txt)
  • Backup Target: Disaster recovery file students_backup.txt.
  • Byte Cloning: FileInputStream & FileOutputStream duplicate raw bytes.
  • On-Demand Trigger: Activated via Menu Option 8.
  • Disaster Recovery: Protects data if primary file is corrupted or lost.
  • Viva Distinction: Character streams handle text; Byte streams copy raw binary.
