1. Introduction

Overview of the Student Performance Analytics Tool

02

Our project is a terminal-based Student Performance Analytics Tool developed using Core Java. It helps teachers manage marks, calculate grades automatically, rank students, and analyze class performance.

1. RECORD MANAGEMENT
  • Developed using Java programming.
  • Helps teachers store and manage student marks.
  • Allows setting up custom academic subjects.
2. AUTOMATIC CALCULATIONS
  • Automatically calculates percentages and grades.
  • Identifies highest and lowest scoring subjects.
  • Eliminates manual calculation mistakes.
3. STUDENT RANKING
  • Compares overall percentages of all students.
  • Ranks students automatically by performance.
  • Uses Java Comparator for fair sorting.
4. PERFORMANCE REPORTS
  • Generates subject averages and top scorers.
  • Provides overall class performance reports.
  • Stores all records in text files for future use.

7. Percentage & Grade Calculation

Formulas, Example, and Grading System

08
PERCENTAGE CALCULATION

Formula: Percentage = (Total Marks Obtained / Maximum Total Marks) × 100

Example: Java = 85 Mathematics = 90 DSA = 75 Total Marks = 250 Maximum Marks = 300 Percentage = (250 / 300) × 100 = 83.33% Calculated Grade = A

11. File Handling & Backup System

How Student Records are Stored and Protected

12
STORAGE (students.txt)
  • Students' information is stored in students.txt.
  • FileWriter and PrintWriter are used to save records.
  • BufferedReader and FileReader load previous records.
  • Records remain available when restarted.
BACKUP (students_backup.txt)
  • Backup is stored in students_backup.txt.
  • FileInputStream & FileOutputStream create backup.
  • Copies raw bytes to ensure an exact duplicate.
  • Prevents data loss if the main file is damaged.
